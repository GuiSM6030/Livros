## Visão Geral
O _Gerenciador Pessoal de Leitura_ é um aplicativo móvel desenvolvido em React Native para ajudar os usuários a gerenciar e acompanhar suas leituras. Com uma interface intuitiva, os leitores podem registrar os livros que estão lendo, acompanhar seu progresso e manter anotações importantes.

## Funcionalidades Principais
- **Cadastro e autenticação de usuários**
- **Registro de livros** com:
  - Título e autor
  - Datas de início e término
  - Número de páginas
  - Anotações pessoais
  - Citações favoritas

- **Visualização detalhada de cada livro**

- **Edição de informações**

- **Exclusão de registros**

- **Acompanhamento do progresso de leitura**

## Tecnologias Utilizadas:
- **Frontend:** React Native
- **Backend:** Firebase (Authentication e Realtime Database)
- **Estilização:** StyleSheet
- **Controle de Estado:** React Hooks

## Design e Interface
O aplicativo utiliza uma paleta de cores em tons de verde e bege, proporcionando uma experiência visual agradável e relaxante para os leitores. A interface foi projetada para ser:
- Intuitiva
- Responsiva
- Acessível
- Consistente em todas as telas

## Telas do Aplicativo
- **Login** - Autenticação de usuários
- **Cadastro** - Criação de nova conta
- **Home** - Listagem de todos os livros
- **Adicionar Livro** - Formulário de registro
- **Detalhes do Livro** - Visualização completa
- **Editar Livro** - Atualização de informações

## Considerações Finais
Este projeto demonstra a aplicação de conceitos de desenvolvimento mobile com React Native, integração com serviços Firebase e construção de uma aplicação completa com autenticação e banco de dados em tempo real. A interface foi projetada para ser intuitiva e acessível, proporcionando uma boa experiência ao usuário final.
